 ## What is a graphical user interface (GUI)

 A Graphical User Interface is a type of user interface that allows people to interact with a computer through visual elements rather than text commands
 ## What is a desktop environment?
 A Graphical User Interface is a type of user interface that allows people to interact with a computer through visual elements rather than text commands
 ## What is the command line interface (CLI)?
 A Command Line Interface is a text-only way to interact with a computer. You type commands and the computer responds with text output.
 ## How do I access the command line interface (CLI)?
 press Ctrl + Alt + T or search for the terminal
 ## What is a virtual console?
 A virtual consoleis a built-in, text-only login session provided directly by the operating system kernel
 ##  What is a terminal emulator?
A terminal emulator is a graphical program that creates a window where you can use the CLI/shell.It emulates old physical terminals 
 ##   What is bash?
 a command language interpreter and scripting language
 ##   What is the shell prompt?
The shell prompt is the line of text that appears in the terminal before you start typing a command.

date +"%Y-%m-%d %H:%M" # Show date and time nicely formatted

free -h                # Show memory usage in human-readable format

## uname
uname -a               # Show all system information

history | tail -n 10   # Show the last 10 commands you ran

## man

## tldr

## cheat

## hostname

## df
df -h                  # Show disk space usage in human-readable form

## du
