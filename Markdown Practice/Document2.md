## 1. Hello, World!

This is the traditional first program in Python. The language is known for its simple, readable syntax and minimal boilerplate.

---

## 2. Variables and Types

Python is dynamically typed — you do not need to declare variable types. You can store numbers, strings, booleans, and more in variables.

---

## 3. Lists

Lists are ordered, mutable collections that can store different data types. They support adding, removing, and accessing elements by index.

---

## 4. Basic Operators

Basic operators include arithmetic operations such as addition, subtraction, multiplication, division, modulus, and exponentiation. They can also be used with strings and lists.

---

## 5. String Formatting

String formatting allows you to insert variables into text. Common methods include the older % operator and modern f-strings.

---

## 6. Basic String Operations

Common string operations include finding length, converting to uppercase/lowercase, slicing, checking substrings, and replacing text.

---

## 7. Conditions

Conditions (if-elif-else statements) allow the program to make decisions based on whether certain conditions are true or false. Logical operators such as and, or, and not are commonly used.

---

## 8. Loops

Loops are used to repeat blocks of code. The two main types are:
- **For loops** — used to iterate over a sequence (like a list or range).
- **While loops** — repeat as long as a condition remains true.
